# EXP 5: COMPARATIVE ANALYSIS OF DIFFERENT TYPES OF PROMPTING PATTERNS AND EXPLAIN WITH VARIOUS TEST SCENARIOS

# Aim: 
To test and compare how different pattern models respond to various prompts (broad or unstructured) versus basic prompts (clearer and more refined) across multiple scenarios.  Analyze the quality, accuracy, and depth of the generated responses 

### AI Tools Required: 
   ChatGPT or any other AI language model tool
   Text analysis or comparison tool (optional for evaluation)
   Word processor for documentation

# Procedure

1) Prepare Multiple Test Scenarios:
     Select several scenarios such as:
		Generating a creative story
		Answering a factual question
		Summarizing an article or paragraph
		Providing advice or recommendations
		Explaining a technical concept

2) Create Two Prompts for Each Scenario:
	 For every scenario, create one naïve prompt and one basic prompt addressing the same task but with different structure and clarity.

3) Run Experiments Using ChatGPT:
	 Input the naïve prompt and record the generated response. 
	 Then input the corresponding basic prompt and record the refined response.
	 Repeat this for all selected scenarios to collect a complete dataset of results.

4) Evaluate Responses:
	 Compare how ChatGPT performs with naïve prompts versus basic prompts based on:
	 	Quality: Clarity, coherence, and organization
	 	Accuracy: Correctness of content and factual reliability
		Depth: Completeness and elaboration of the explanation

5) Analyze the Findings:
	 Determine whether ChatGPT consistently provides better results with basic prompts.
	 Identify scenarios where naïve prompts might perform equally well or poorly.

6) Deliverables:
	 A comparative table of ChatGPT’s responses for naïve and basic prompts
	 Observations on how prompt clarity affects output quality, accuracy, and depth
	 Summary of findings and best practices for effective prompt creation
